# Write like a human, resumes

For resume bullets and summaries. Everything in the default card holds, with these changes:

- Bullets, no `I`. Start with a plain verb or with the result.
- Every bullet carries a number, a name or a date, or it goes.
- Two or three bullets per role matter more than the others. Let the rest be short and functional.
- Vary the shape. Not every bullet is verb, object, result. Some lead with the result, some with the context.
- No adverb before the verb (`successfully led`, `effectively managed`). The result shows it.
- Be honest about scope: `configured` when you configured it, `led` only when you led it.
- Ceilings per five bullets: one em dash, one semicolon. Per resume: two colon-then-list bullets. Ellipses never.
- Run `/wlah check --kind resume` before it leaves.
